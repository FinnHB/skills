## 2026-07-02 (v0.5.0)
Output of an orchestrated external review (user request): three parallel research agents — an opus literature survey of multi-agent debate / LLM-critique research, a docs agent verifying every hard-coded harness fact, an opus red-team hunting failure modes not already in this changelog — plus the orchestrator's own repo review. Changes by cluster:

- **Enforcement — the protocol now leaves residue.** The red-team's top finding was that compliance was unobservable: a rushed orchestrator could emit a plausible report without spawning anyone. Now: report Stats are receipts copied from each spawn's returned `subagent_tokens`/`duration_ms`, never estimates ("a report that cannot list its spawns describes a check that did not run"); spawn prompts are assembled from fill-in-the-blank templates (`references/spawn-templates.md`) so a dropped canary is a visible hole; each brief constraint carries quote + conversation locator, making "I re-read the conversation" checkable; the Skeptic's substantiated/soft classification is binding — the orchestrator can no longer launder a substantiated objection down to a soft concern (the upstream twin of the v0.2.0 Adjudicator fix, which had only closed the rebuttal exit).
- **Effort default flipped to full.** Light-tier self-selection by the biased author was a v0.2.0 soft concern never fixed; "this doesn't need a panel" is the one judgment the author can't make neutrally. Downgrading to light now requires a one-line argument (blast radius, why limited), and a pre-flight tells the user tier/roles/cost envelope before the first spawn.
- **Cross-lineage Adjudicator via ask-the-panel** (user decision). Research basis: LLM self-preference bias (cited research puts it at ~0.52 for judging own-model text — figure unverified against the source paper, see run record; the qualitative claim stands independently) tracks fluency/familiarity rather than labels, so it survives blinding — a same-lineage Adjudicator systematically favors the orchestrator's fluent rebuttal, and no prompt hygiene fixes it. The Adjudicator is the one role external models fit: evidence-only by design, no tools needed (the objection that deferred cross-vendor critics in v0.3.0). Mechanics: packet file → `panel.py --mode adjudicate` (new system prompt added to ask-the-panel 0.3.0), subject to that skill's privacy confirmation; local fallback recorded as same-lineage caveat. Packet debiasing per the judge-bias literature: objection = the Skeptic's report section in full (never an orchestrator excerpt — the include/omit asymmetry from the v0.2.0 brief fix, re-applied to adjudication), randomized order, comparable length.
- **Verifier: factored, six dispositions.** Claims and check-plan are listed before reading the artifact's rationale (Chain-of-Verification: factored verification stops the checker copying the draft's own reasoning). Confirmed/contradicted/uncheckable gains three classes the trichotomy silently swallowed: "no counterexample found" (universal/absence claims were being booked confirmed), "self-referential" (applied artifacts were verified against their own effects), "unverified by asymmetry" (credential/network-gated claims passed as uncheckable exactly where the author was better provisioned than the critic).
- **Staleness fails loud.** All harness facts quarantined into dated `references/harness-assumptions.md` with a halt-if-absent pre-flight rule — the red-team's "the skill lies confidently instead of failing loud" scenario. Drift found and recorded there: SendMessage is now always available for resuming subagents (the v0.2.0 fresh-spawn rebuttal's gating evidence is stale; the rule stands on its anchoring argument), and agents now run in the background by default (triage waits for all panelists).
- **Model-agnostic parent** (user decision: Fable is transient; sessions will typically run sonnet). All "authoring session is typically opus" framing removed; `model: sonnet` stays the panel default with a halt-never-inherit rule if the alias stops resolving; a sonnet-on-sonnet run now records "zero model diversity" in Caveats — which is what makes cross-lineage adjudication load-bearing rather than nice-to-have.
- **Smaller fixes:** Skeptic severity is ranked against the §1 claim (severity is the least reliable critic judgment); a saturated 5-objection budget must be declared (cap-exhaustion is not clearance); long artifacts pass by file path and binding constraints sit first/last in the brief (lost-in-the-middle); mid-check user edits mark results stale; unanimity yellow flag now carries an action (offer /ask-the-panel follow-up).
- **Structure:** first use of progressive disclosure — verbatim obligations/templates and the harness catalog moved to `references/`, keeping SKILL.md operative at roughly its previous length. Frontmatter gains `metadata.version` (repo convention from ask-the-panel).
- **Validated by the research, deliberately unchanged:** evidence-gated objections (intrinsic self-correction demonstrably lowers accuracy; external grounding is what helps), fresh-agents-per-round and the hard cap (debate degrades over rounds; agreement pressure flips correct answers more than wrong ones), the Rival as dialectical inquiry (outperforms devil's advocacy on assumption-surfacing), and the rejection of majority voting and inter-agent chatter.

## 2026-06-07 (v0.1.0)
- Initial version, hardening a prompt the user had been retyping ("spin up multiple agents, including adversarial agents, to critically assess your plan/results/findings/conclusions… keep doing this until consensus"). The free-form version has three known failure modes the skill designs against:
  - **Consensus theater** — "until consensus" terminates on agreement, so the loop is biased toward producing it. Fix: an objection only counts with named evidence (file:line, command output, redone computation), a rebuttal is held to the same standard, rounds are hard-capped at 3, and dissent surviving the cap ships in the report as a finding rather than being argued away.
  - **Correlated bias** — same-model agents agreeing is weaker evidence than it feels; cold context removes conversational bias, not model bias. Fix: roles with different evidence obligations (Skeptic falsifies, Verifier checks claims with tools, Rival re-derives blind), and unanimous fast round-1 sign-off is recorded as a yellow-flag caveat, never as upgraded confidence.
  - **Blinding leaks** — passing the orchestrator's reasoning to critics reintroduces the contamination the agents were spawned to avoid. Fix: §2 mandates artifact + original brief only; the Rival doesn't even get the artifact.
- Other decisions: fresh Skeptic per re-check round (a reused agent carries the debate history); orchestrator defaults to conceding when evidence stands against it ("the most biased participant in the room"); proportional effort tiers (light = 2 agents 1 round, full = 3 roles ≤3 rounds) so trivial checks don't burn a panel; mandatory report template because subagent final messages are invisible to the user.
- Rejected: multi-model debate (community skills pair Claude with GPT — out of scope for a single-harness skill, revisit if model-bias flags recur in practice); fixed large reviewer panel à la agent-review-panel (proportionality matters more than headcount); merging into grill-me (opposite direction of interrogation — grill-me grills the human about their plan, this grills Claude about its output).
