## 2026-06-07 (v0.2.0)
- First real run was the skill checking itself (full mode, 3 rounds, 7 agents: 3 Skeptics, 3 Verifiers, 1 Rival — each round's critics spawned cold). Every Verifier confirmed every checkable harness claim against live docs; every Skeptic found new substantiated objections, all conceded or adjudicated below. Net: 17 substantiated objections, 16 conceded, 1 rebutted.
- **Round 1 concessions** (v0.1.0's failure modes): the brief was an unconstrained orchestrator-authored leak channel (now: quote user constraints verbatim, assemble mechanically by re-reading, never paraphrase); "includes ONLY" was factually false — the harness force-injects CLAUDE.md + auto-memory into `general-purpose` agents, only Explore/Plan skip them (now acknowledged as an uncontrollable leak, reported in Caveats); the Rival's blinding broke via the filesystem for applied/saved artifacts (now: skip the role, never book convergence-by-discovery); light-mode "single round" contradicted the unconditional §5 re-check (now: "one round" = the no-revision path); the agent-Q&A channel was unexecutable by default and leaked reasoning (now: answers fold into the artifact/brief as neutral premises); the re-check dropped the Verifier exactly when fresh claims appeared (now: re-check adds a Verifier if revisions changed factual claims); user-named artifacts got rewritten unbidden (now: ownership rule — report, never edit, unless asked); Rival divergence had no materiality filter (now: different claim/number/outcome = objection, equivalent shape = alternative considered). Adopted from the blind Rival's competing design: 5-objection cap + smallest-fix per objection in the Skeptic obligation, Skeptic-only light floor, capitulation-consensus guard ("an artifact nobody can object to because it asserts nothing is worse than recorded dissent"), artifact freezing, optional model-diversity lever.
- **Round 2 concessions**: fork mode (staged rollout, undetectable from the env var) silently voids cold-start — added the canary line to every agent prompt as a tripwire plus the `CLAUDE_CODE_FORK_SUBAGENT=0` remediation; the orchestrator was terminal judge of its own rebuttals, so a contested objection could ship under "Survived" graded only by the most biased participant — rebuttals now go to a fresh Adjudicator or book as dissent; verbatim-quoting prevented distortion but not omission (an omitted constraint shares its cause with the misreading under test) — brief assembly is now mechanical, not recall-based.
- **Round 3 concessions** (cap reached; these fixes ship un-rechecked, per the new cap-precedence rule they themselves introduced): the Adjudicator couldn't be spawned without violating §2 (now a sanctioned, specified exception with a verbatim obligation); cap-vs-re-check precedence was undefined for final-round concessions (now: revision ships flagged un-rechecked in Caveats); auto-compaction silently turns "re-read the conversation" into reading your own paraphrase (now: recover from the on-disk transcript or confirm the brief with the user); the Rival-independence rule covered the worktree but not injected auto-memory — empirically demonstrated: this run's own agents received this repo's MEMORY.md (now: same skip rule); `CLAUDE_CODE_SUBAGENT_MODEL` silently outranks per-invocation model choices (now checked before spawning).

Evidence against: SendMessage is gated behind `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` (off by default — both Verifiers), and the Rival's own design conceded the anchoring problem ("the original panel is anchored on its own objections and cannot see regressions"), which applies equally to an agent re-judging its own objection. Fresh-spawn-only stands; divergence logged.

## 2026-06-07 (v0.1.0)
- Initial version, hardening a prompt the user had been retyping ("spin up multiple agents, including adversarial agents, to critically assess your plan/results/findings/conclusions… keep doing this until consensus"). The free-form version has three known failure modes the skill designs against:
  - **Consensus theater** — "until consensus" terminates on agreement, so the loop is biased toward producing it. Fix: an objection only counts with named evidence (file:line, command output, redone computation), a rebuttal is held to the same standard, rounds are hard-capped at 3, and dissent surviving the cap ships in the report as a finding rather than being argued away.
  - **Correlated bias** — same-model agents agreeing is weaker evidence than it feels; cold context removes conversational bias, not model bias. Fix: roles with different evidence obligations (Skeptic falsifies, Verifier checks claims with tools, Rival re-derives blind), and unanimous fast round-1 sign-off is recorded as a yellow-flag caveat, never as upgraded confidence.
  - **Blinding leaks** — passing the orchestrator's reasoning to critics reintroduces the contamination the agents were spawned to avoid. Fix: §2 mandates artifact + original brief only; the Rival doesn't even get the artifact.
- Other decisions: fresh Skeptic per re-check round (a reused agent carries the debate history); orchestrator defaults to conceding when evidence stands against it ("the most biased participant in the room"); proportional effort tiers (light = 2 agents 1 round, full = 3 roles ≤3 rounds) so trivial checks don't burn a panel; mandatory report template because subagent final messages are invisible to the user.
- Rejected: multi-model debate (community skills pair Claude with GPT — out of scope for a single-harness skill, revisit if model-bias flags recur in practice); fixed large reviewer panel à la agent-review-panel (proportionality matters more than headcount); merging into grill-me (opposite direction of interrogation — grill-me grills the human about their plan, this grills Claude about its output).
