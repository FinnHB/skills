# /scope-paper — Synthesis and scope commitment

You are running the second phase of the greenfield pipeline per ADR 0006. Your single job is to synthesize what is already in `worklog/IDEA.md` and the paper-level `worklog/CONTEXT.md` into `worklog/RESEARCH_BRIEF.md`, then commit the model class to `THEORY_PRIORS.md`.

**There is no interview in this command.** This is explicit and non-negotiable per ADR 0006. Do not ask clarifying questions. Do not say "just one more question." If the existing documents are insufficient to populate a required field, refuse with a specific missing-field message and send the user back to /start-paper. The documented failure mode of adding an interview step to /scope-paper is "mixed-mode confusion" — the scoper that asks questions becomes the griller again, defeating the separation of concerns the three-command pipeline exists to enforce.

## Precondition check

Read `worklog/IDEA.md`. If the file does not exist or is empty (contains only the bootstrap comment), refuse:
> "worklog/IDEA.md is empty. /scope-paper requires a completed /start-paper session. Run /start-paper to grill the idea fully before scoping."

## Synthesis — produce worklog/RESEARCH_BRIEF.md

Read, in order:
1. `worklog/IDEA.md` (full content)
2. The paper-level `worklog/CONTEXT.md` (full content)

Synthesize these into `worklog/RESEARCH_BRIEF.md` with exactly the following six fields. Each field must be a non-empty, non-placeholder value synthesized from the grilled discussion. Write in prose where specified; use a short declarative phrase where noted.

```markdown
# worklog/RESEARCH_BRIEF.md

Generated by: /scope-paper
Generated at: {ISO-8601 timestamp}
Source: worklog/IDEA.md + worklog/CONTEXT.md

---

## Research question
{One paragraph stating the precise research question. What phenomenon is being explained, and what causal or equilibrium mechanism does this paper illuminate?}

## Contribution claim
{What is new. How this paper advances the literature beyond the current frontier. One paragraph.}

## Identification strategy
{How the key causal or equilibrium claim is identified. Theoretical: the model mechanism + comparative statics. Empirical: the quasi-experimental variation, IV, or structural estimation approach. One paragraph.}

## Model class candidate
{Short declarative phrase, e.g., "two-country NK-DSGE with incomplete markets and FTPL elements" or "Gabaix (2020) sparsity extension to open-economy NKM." This value is written to THEORY_PRIORS.md on gate pass.}

## Data plan
{Which datasets, sample period, frequency. Write "Theoretical — no empirical data" if purely theoretical. One paragraph or bullet list.}

## Target journal
{One of: AER | JPE | JIE | RES | QJE | ReStud. State the primary target and one fallback.}
```

## Checklist gate — deterministic lint (no LLM call)

After writing worklog/RESEARCH_BRIEF.md, lint it deterministically. This lint must not use an LLM judgment call. Parse the document and check:

For each of the six required fields (`Research question`, `Contribution claim`, `Identification strategy`, `Model class candidate`, `Data plan`, `Target journal`):
- The section header exists in worklog/RESEARCH_BRIEF.md.
- The section body is non-empty.
- The section body does not contain placeholder text: `TODO`, `TBD`, `N/A`, `{`, `}`, or an empty string.

If any field fails:
- Do NOT update THEORY_PRIORS.md.
- Refuse with exactly: "Required field <field name> in worklog/RESEARCH_BRIEF.md is missing or still a placeholder; return to /start-paper to discuss further before running /scope-paper again."
- Stop. Do not continue to the THEORY_PRIORS.md update.

If all six fields pass, proceed to the state machine update.

## THEORY_PRIORS.md update — on gate pass only

Read `THEORY_PRIORS.md` in full before writing.

Perform the following three changes in a single focused Edit — do not mix this with any other file operations:

**1. Write model class to the Declared block.**
In the `## Declared model class` section, replace the empty/placeholder content with:

```
Status: declared
Class: {value from worklog/RESEARCH_BRIEF.md ## Model class candidate}
Key assumptions: (to be elaborated during /draft-paper)
Key parameters and prior ranges: (to be elaborated during /draft-paper)
```

**2. Transition model_class_status from "candidate" to "declared" in YAML frontmatter.**
Change:
```yaml
model_class_status: candidate
```
to:
```yaml
model_class_status: declared
```

Also update `last_updated` to today's date and `last_updated_by` to `agent`.

Note: Phase 7's PreToolUse hook will enforce the `candidate → declared → locked` state-machine transition mechanically. This prompt-level instruction is the current enforcement until that hook is built.

**3. Append a Decision-log entry.**
Append to the `## Decision log (append-only)` section — do not edit any existing entries:
```
- {YYYY-MM-DD} [claude]: model class declared via /scope-paper — {model class value}
```

## Exit

After successfully completing the checklist gate and THEORY_PRIORS.md update, report to the user:
- Confirmation that worklog/RESEARCH_BRIEF.md has been written with all six fields.
- Confirmation that model_class_status has been transitioned to `declared` in THEORY_PRIORS.md.
- The declared model class value (for user verification).
- Instruction: "Review worklog/RESEARCH_BRIEF.md. When you are ready to begin drafting, invoke /draft-paper."

Do not invoke /draft-paper. Transitions are user-invoked per ADR 0006.
