  click P1 call nodeDetail() "First run seeds the database from the word list, computes semantic embeddings, and resolves which earlier decks count as already known."
  click P2 call nodeDetail() "Adds pinyin, a definition, and a difficulty score to every card, generated in parallel and cached so re-runs are free."
  click P3 call nodeDetail() "Writes one example sentence per word using only vocabulary the learner already knows, then validates it deterministically with an LLM remediation fallback."
  click P4 call nodeDetail() "Two-tier image pipeline: a scene description is written first, then rendered and compressed. Identical prompts are never rendered twice."
  click P5 call nodeDetail() "Terminal review sessions scheduled by a spaced-repetition algorithm, with the queue sorted by how close each card is to being forgotten."
  click Z call nodeDetail() "The database is the single source of truth; a report tool aggregates telemetry into per-run summaries."
