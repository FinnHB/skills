  click P1 call nodeDetail() "First run seeds the database from the word list, computes embeddings, and resolves which earlier decks already count as known."
  click P2 call nodeDetail() "Adds pinyin, a definition, and a difficulty score to every card — generated in parallel and cached, so re-runs are free."
  click P3 call nodeDetail() "Writes one example sentence per word using only vocabulary the learner already knows, then checks it deterministically; failing sentences are repaired automatically."
  click P4 call nodeDetail() "A scene description is written first, then rendered and compressed; weak prompts improve themselves before any rendering is paid for."
  click P5 call nodeDetail() "Terminal review session with the queue sorted by how close each card is to being forgotten."
  click P6 call nodeDetail() "Each grade updates the card's memory model and books its next review date — tomorrow's session picks up whatever is due."
  click Z call nodeDetail() "Retention builds across sessions; a report tool turns telemetry logs into per-run quality metrics."
